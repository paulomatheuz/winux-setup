# Configurações do Komorebi

`komorebi.json` e `komorebi.bar.json` são as configurações pessoais encontradas no inventário. A referência de esquema acompanha o Komorebi 0.1.41, versão do ambiente e do catálogo de instalação.

`applications.json` é a cópia das regras presente no ambiente local. A base vem de [komorebi-application-specific-configuration](https://github.com/LGUG2Z/komorebi-application-specific-configuration), de Jade Iqbal e colaboradores, sob licença MIT, reproduzida em `applications.LICENSE`. A cópia local foi preservada; ela não é substituída automaticamente pela versão mais recente da origem.

O setup adapta somente o caminho de `applications.json` no arquivo instalado. Os arquivos versionados mantêm as preferências pessoais. Veja [aplicação, destinos e limitações](../../docs/komorebi.md).
