# Recursos do ambiente

- `screenshots/`: prévia pública já usada no README.
- `wallpapers/`: os 18 arquivos da coleção pessoal usada pelo YASB.
- `icons/terminal.ico`: ícone Gengar usado no perfil do Windows PowerShell.
- `manifest.json`: seleção explícita e SHA-256 dos arquivos aplicados pelo setup.

Os arquivos foram importados sem alterações de conteúdo. O instalador não gera imagens, não escolhe uma imagem como wallpaper e não apaga arquivos extras do destino. Veja [Recursos visuais](../docs/recursos-visuais.md).
